# Проверка русской адаптации в Linux

Дата проверки: 5 ноября 2026 года.

Среда: Ubuntu 24.04 LTS, WSL2, x86_64, Node.js `v24.22.2`. Архив Node получен с nodejs.org, SHA-256 сверен с опубликованным `SHASUMS256.txt`. Системный Node Windows не заменялся. Использована отдельная копия проекта в файловой системе Linux; зависимости установлены с `npm ci --ignore-scripts`.

## Объем проверки

- Поведенческие тесты ядра, HTTP, ключей, карточек и ролей.
- Исполнители, возобновление сессий, восстановление результата и отмена процессов с тестовыми CLI.
- GitHub/GitLab webhook, каналы и готовые сценарии с локальными стендами.
- Установка, обновление, резервное копирование и восстановление.
- Регрессии русского интерфейса и совместимость исторических маркеров.
- Детерминированная симуляция на 200 000 шагов и ограниченный перебор 40 320 порядков действий.
- Типы TypeScript, форматирование, метаданные Skill и внутренние ссылки.

## Результаты

Полный `npm test` завершился успешно: 657 тестов, 650 пройдено, 0 ошибок, 7 платформенных проверок пропущены. Пройдены симуляция на 200 000 шагов и перебор 40 320 порядков действий. `npm run typecheck`, `npm run format:check` и `npm run check:ru` также завершились без ошибок.

Проверки выполнялись локально в Linux. GitHub Actions этого приватного репозитория оставлены отключенными; их успешный запуск здесь не заявляется.

Проверка `scripts/install-smoke.sh` завершилась успешно. Она установила код из зафиксированного коммита, запустила сервис, получила вопрос, ответила на карточку, дождалась продолжения работы и удалила программу с сохранением данных. Внешний агент и уведомления заменены тестовыми программами; рабочие сообщения не отправлялись.

Независимое ревью проверило сохранение ролей и полей протокола, исторических маркеров, границы данных и инструкций, ограничений ревью PR и источника установки. Для установки в инструкции явно указан репозиторий адаптации; тест проверяет отказ при несовпадении явно заданного источника.

## Воспроизведение

```sh
npm ci --ignore-scripts
npm run typecheck
npm run format:check
npm run check:ru
npm test
sh scripts/install-smoke.sh
```

Для тестов сценариев нужен `jq`. Его отсутствие первоначально вызвало три ошибки исходного проекта; после установки зависимость доступна в стенде. Системная служба и платный CLI-агент в рабочем профиле пользователя не запускались. Эти результаты относятся к Linux в WSL2 и не подтверждают нативную поддержку Windows или тестирование на macOS.
