# Состояние русской адаптации

Русская адаптация охватывает пользовательские интерфейсы, инструкции агентам, документацию, сценарии и архитектурные изображения. Имена API и конфигурационных полей сохранены.

| Область | Состояние |
|---|---|
| Основной README | Русское описание, установка и сценарии |
| Архитектурная иллюстрация | Основная и отдельная русская SVG-схема, PNG |
| Отчет по безопасности | На русском |
| CLI, ошибки и диагностика | На русском, даты и числа используют русскую локаль |
| Системные уведомления и шаблоны каналов | Стандартные тексты на русском |
| Подсказки агенту и восстановление результата | На русском; разделение инструкций и данных сохранено |
| Страница карточки | Русские подписи и `lang="ru"` |
| Полный протокол и документация плагинов | На русском, внутренние якоря проверяются |
| Сценарии, SKILL и инструкции установки | На русском, метаданные Skill сохранены |
| Инструкции разработчикам и вклад в проект | На русском |

Имена CLI-команд, JSON-полей, API-маршрутов, переменных среды и продуктов сохраняются. Парсер читает `FAILED`, `NOTHING`, `НЕ ВЫПОЛНЕНО`, `НЕТ ЗАДАЧ` и прежние китайские маркеры. Существующие пробные задачи и карточки распознаются по историческим именам. Регрессионные тесты проверяют эту совместимость, разделение данных и инструкций и экранирование карточек.

`architecture.svg` и `architecture.ru.svg` содержат русские подписи. `architecture.ru.png` - растровая версия. Английская схема и README сохранены как справочный вариант; исходный китайский README находится в `README.zh-CN.md`. Китайские строки в тестовых данных намеренно проверяют прием произвольного Unicode и совместимость; это не стандартный интерфейс.

`npm run check:ru` проверяет рабочие тексты, метаданные Skill, внутренние ссылки и короткие дефисы. Проверка в Linux использует Ubuntu 24.04 в WSL2 и Node 24. Реальный платный CLI-агент не вызывается автоматическими тестами; полный цикл установки проверяется тестовым агентом и фиктивными уведомлениями. Системные ошибки ОС, сообщения внешних программ и пользовательские данные сохраняются в исходном виде.

Перевод подготовлен с машинным черновиком и ручной редактурой. Основные подсказки, установка, Skill, безопасность и правила разработки переписаны вручную; независимое ревью проверяет сохранение полномочий и ограничений. Русификация сама по себе не является полным аудитом безопасности внешних CLI и плагинов.
