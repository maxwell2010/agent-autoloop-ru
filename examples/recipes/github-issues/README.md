# Решение проблемы на GitHub

<a id="section-3"></a>
## Что решить
Читайте новый выпуск каждые пять минут, меняйте код локально и уведомляйте вас о необходимости его проверки; не отправляйте, не отправляйте и не отвечайте на проблему.

<a id="section-6"></a>
## Как включить
Скопируйте `SKILL.md` этого каталога в `~/.codex/skills/handle-issue/`; Клод Код использует `~/.claude/skills/handle-issue/`.
Объедините `sources`, `agents` и `rules` из `rules.json` в `~/.agent-autoloop/rules.json`, а затем проверьте:
```bash
agent-autoloop check
```
Компьютер приема заказов требует входа в систему `gh`; сценарий опроса передает текст агенту.

<a id="section-14"></a>
## Что следует изменить?
- В двух местах `worker` заменен компьютером приема заказов; `use` заменяется на `codex` или `claude`.
- `owner/repo` заменяется на репозиторий, `created:>=2026-11-04` заменяется на дату активации; `cwd` заменяется чистым каталогом проекта.
- Права доступа: `edit`. Агент только читает данные и изменяет локальные файлы; Работа в сети завершается фиксированным сценарием опроса, который не ограничен `access`. По умолчанию Клод не запускает никаких тестовых команд, см. [Описание разрешения](../../../docs/plugins.md#section-105).
