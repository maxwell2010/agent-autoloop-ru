#ежедневный утренний отчет

<a id="section-3"></a>
## Что решить
Каждое утро организуйте заметки и материалы текущего каталога и пишите на `briefs/YYYY-MM-DD.md` без подключения к Интернету.

<a id="section-6"></a>
## Как включить
Скопируйте `SKILL.md` этого каталога в `~/.codex/skills/morning-brief/`; Клод Код использует `~/.claude/skills/morning-brief/`.
Объедините `agents` и `rules` из `rules.json` в `~/.agent-autoloop/rules.json`, а затем проверьте:
```bash
agent-autoloop check
```
Правила вступят в силу в течение нескольких секунд; временно установите cron на `* * * * *` для пробного запуска в течение одной минуты.

<a id="section-14"></a>
## Что следует изменить?
- `worker` заменяется компьютером приема заказов, отображаемым `agent-autoloop status`; `use` выбирает `codex` или `claude`.
- `cwd` заменяется существующим каталогом заметок; `cron` - местное время, которое по умолчанию составляет восемь часов каждый день.
- Права доступа: `edit`. Оба плагина могут читать локальные данные и писать утренние отчеты; они не требуют подключения к Интернету или каких-либо команд оболочки, см. [Описание разрешения](../../../docs/plugins.md#section-105).
